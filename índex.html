Controle diário de produção

Selecione um lote.
Automático: ao salvar, a data avança para o dia seguinte e a idade em semanas é recalculada pela data de nascimento do lote. Os campos do novo dia são limpos.
Proteção dos registros: cada salvamento gera identificação única, horário do lançamento, histórico de alterações e uma cópia de segurança interna automática.

Cadastro de lotes

Histórico mensal / ficha para impressão

Importar dados existentes

Selecione o arquivo de backup para copiar somente cadastro dos lotes e registros diários de produção. Vendas, clientes, fábrica, funcionários e financeiro não são importados.
Nenhuma importação realizada nesta instalação.

Segurança dos dados

A importação apenas copia os dados de produção para este controle, sem alterar o arquivo de origem.

Histórico de alterações

Correções ficam registradas com data e hora. O sistema não apaga silenciosamente o histórico de um registro substituído.
